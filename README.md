# FLUTON CAT TANKS

## Controls
- Aim and power: sliders
- Move: on-screen buttons, or A / D
- Fire: FIRE CANNON button or Space
- Arrow Up / Down: adjust aim

## Important token note
The `$FLUTON` balance and rewards are local demo points stored only in the current game session. They are **not real blockchain tokens**, are not connected to a wallet, and cannot be withdrawn or transferred. A production version needs a backend, wallet authentication, anti-cheat validation, and a verified Fluton token contract before any real rewards are issued.

## Current prototype features
- Three black-cat pilots with different stats
- Destructible rolling terrain and projectile physics
- Wind variation, aiming angle, firing power
- CPU tank opponent and health bars
- 10-minute match timer
- Stage progression and item shop


## Official logo asset
The supplied `fluton-logo.png` is included as-is and displayed in the game header and character-selection screen. It is not redrawn, recolored, cropped, or modified.
